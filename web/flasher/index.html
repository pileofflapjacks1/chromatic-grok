      Technical details
      USB port
      ESP32 serial 0x374E:0x0101 only. 0x33AA:0x0120 is the Chromatic's JTAG bridge (not the ESP32 console) and is filtered out.
      Serial
      115200 baud only, no baud change. ClassicReset with DTR and RTS always set together. Stub loaded before MD5.
      Chip
      not connected

      Backup checks
        Partition table (current)

        Firmware to install

        Writes
        Install: only 0x8000 (partition table) and 0x10000 (app, at most 0x1F0000), each SHA-256 checked against manifest.json first and MD5 checked on the chip after. Restore: the full 4 MB at 0x0. Never 0x1000, no full-chip erase, no eFuse writes.
        Advanced
        Saves the 4 MB image from the last backup without the header. It can't be restored on this page.
